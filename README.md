# Hotraco / Speria Field Service Manager

Expo-app (web + iOS/Android) voor Field Service Engineers, Service Managers en Planning.

## Inloggen (demo)
| Rol | Voorbeelden | PIN |
|-----|-------------|-----|
| Medewerker | Jan de Vries, Sara Bakker, Tom Jansen | `1234` |
| Manager | Service Manager, Planning Lead | `9999` |

## Procedure overuren
1. Medewerker registreert uren.
2. Weken mét overuren verschijnen onder **Overuren**.
3. **Week indienen** = doorsturen naar manager (zoals Excel).
4. Manager logt in en kiest: **TVT**, **Uitbetalen**, **Gemengd**, **Info vragen** of **Afwijzen**.
5. TVT-saldo / loonstrook blijven in andere systemen.

## Starten
```bash
npm install
npx expo start --web --clear
```
